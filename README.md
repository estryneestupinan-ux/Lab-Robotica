
# Lab de Robótica

## Descripción del proyecto

Este repositorio reúne el desarrollo del proyecto del laboratorio de robótica, enfocado en el diseño de una línea de producción robotizada para una fábrica de aceites.

La propuesta busca automatizar las principales etapas del proceso productivo, desde la manipulación del aceite hasta el llenado, sellado y transporte de los envases, mediante la coordinación de diferentes robots manipuladores.

## Objetivo

Aplicar conceptos de robótica, cinemática, control y planeación de trayectorias para desarrollar un sistema automatizado que mejore simule el proceso que se podría ver en una planta de llenado y envasado de aceites con el fin de ver si podría aplicarse a un entorno real donde pueda disminuir la exposición de los operarios en esta tarea potencialmente peligrosas.

## Alcance

El proyecto contempla el diseño y modelado de los manipuladores, la simulación de sus movimientos y la integración de herramientas de software para representar y evaluar el funcionamiento de la línea de producción en un entorno controlado.

## Contenido

En este repositorio se encuentra el código fuente, los modelos robóticos, las simulaciones y la documentación técnica relacionada con el desarrollo del proyecto.
