# Código fuente ROS 2

Esta carpeta contiene los paquetes de software del robot SCARA.

## Contenido

- Descripción del robot mediante URDF o Xacro.
- Archivos launch para iniciar los componentes del sistema.
- Mallas del modelo, cuando sean necesarias.
- Configuraciones y parámetros de los controladores.
- Nodos y scripts propios del proyecto.

## Entorno

- Sistema operativo: Ubuntu.
- Middleware: ROS 2 Jazzy.

## Instalación y ejecución

Documentar los paquetes necesarios, los comandos de compilación y los procedimientos de lanzamiento verificados para el proyecto.
