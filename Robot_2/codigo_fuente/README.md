# Código fuente del robot SCARA

Esta carpeta contiene los programas y paquetes necesarios para ejecutar, simular y controlar el robot.

## Organización

- `ros2/`: paquetes de ROS 2, descripción URDF/Xacro, archivos launch y configuraciones.
- `microcontrolador/`: firmware, proyectos de programación y documentación de hardware.
