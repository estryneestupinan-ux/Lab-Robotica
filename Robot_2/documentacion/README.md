# Documentación técnica del robot SCARA

Esta carpeta contiene la documentación del diseño, implementación, simulación y validación del manipulador robótico SCARA.

## Organización

- `arquitectura/`: diagramas de arquitectura del sistema.
- `diagramas_secuencia/`: secuencias de los procesos.
- `planos/`: planos y ensambles mecánicos/electricos.
- `memorias_calculo/`: cálculos, ecuaciones y justificaciones de diseño.
- `manual_usuario/`: instrucciones de instalación, operación y solución de problemas.
