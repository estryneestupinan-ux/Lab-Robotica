# Desarrollo_Robot_Empaquetado

Este repositorio reúne el código fuente y la documentación técnica relativos al diseño y desarrollo de un **brazo robótico scara de 3 grados de libertad**, orientado al empaquetado final de las botellas para su distrubución.

## Descripción

Este proyecto presenta el proceso operativo de un robot encargado del **transporte y vaciado de envases de aceite** dentro de una planta de procesamiento hipotética.

El repositorio contiene la documentación correspondiente al diseño mecánico, electrónico y de control del sistema robótico.
